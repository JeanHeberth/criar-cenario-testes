## 📋 Ferramentas de Visualização

### GitHub
Os arquivos Mermaid são renderizados automaticamente no GitHub.

### VS Code
Instale: "Markdown Preview Mermaid Support"

### Draw.io
1. Abra draw.io
2. Selecione "Import from" → "GitHub"
3. Copie o conteúdo do arquivo Mermaid
