# Uso no Mac e Windows

## Pré-requisito
O Spring Boot e o projeto de automação devem estar na **mesma máquina**.

## Caminho do projeto
- Mac: `/Users/<usuario>/Development/qa/automacao-playwright`
- Windows: `C:\\Development\\qa\\automacao-playwright`

## Observação frontend
O navegador não fornece o caminho absoluto da pasta local; o usuário informa o texto do caminho.

## Execução de comandos
- Mac/Linux: `npm`, `npx`
- Windows: `npm.cmd`, `npx.cmd`
