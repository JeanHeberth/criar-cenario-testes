# Auto QA BMAD

Módulo para analisar projeto de automação, planejar implementação de teste, gerar artefatos para revisão e aplicar/validar com segurança.

## Escopo v1
- Playwright + TypeScript
- Cypress + TypeScript

## Fluxo resumido
Validação de projeto → Descoberta → Análise → Plano → Geração → Revisão → Aplicação → Execução → Relatório.
